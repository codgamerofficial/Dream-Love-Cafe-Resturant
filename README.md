## Features

1. **"Dream Love — Midnight Café" Visual Identity**: Deep espresso `#120F0E` background, warm cream typography, muted copper `#C87D53` accents, and golden highlights.
2. **Complete Digital Menu**: Live search, category filtering, veg/non-veg toggle, chef specials filter, and availability status. Unpriced items cleanly display "Ask for price".
3. **Instant WhatsApp Checkout**: Converts persistent local cart items into formatted WhatsApp orders targeting `+919933388167`.
4. **Table Reservation System (`/book`)**: Validated booking form storing table requests in Supabase with status lifecycle (`pending`, `confirmed`, `completed`, `cancelled`).
5. **Admin Portal (`/admin`)**: Authenticated dashboard for managing menu items, gallery photos, table reservations, and operational restaurant settings.
6. **Editorial Gallery**: Masonry layout on desktop, responsive grid on mobile, and full-screen lightbox.
7. **SEO & Structured Data**: OpenGraph meta tags and JSON-LD `Restaurant` / `LocalBusiness` schema.

## Quick Start

```bash
# Install dependencies
npm install

# Run web development server
npm run web

# Run tests
npm test

# Export static production web build
npm run build:web
```
