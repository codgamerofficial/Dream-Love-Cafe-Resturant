# Environment Variables Reference

| Variable | Description | Default / Example |
|---|---|---|
| `EXPO_PUBLIC_SUPABASE_URL` | Public Supabase project URL | `https://xyz.supabase.co` |
| `EXPO_PUBLIC_SUPABASE_ANON_KEY` | Public Supabase client anon key | `eyJhbG...` |
| `EXPO_PUBLIC_SITE_URL` | Canonical public web URL | `https://dreamlove.pages.dev` |

> Note: Never commit Supabase service-role keys or sensitive credentials into source control.
