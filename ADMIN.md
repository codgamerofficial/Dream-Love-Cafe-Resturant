# Admin Portal Documentation

## Accessing Admin Panel

- Route: `/admin`
- Demo credentials (Offline / Testing mode):
  - **Email**: `admin@dreamlove.com`
  - **Password**: `admin123`

## Features

1. **Dashboard**: Live metrics on menu counts, chef specials, gallery items, and system health.
2. **Menu Management**: Create, edit, toggle availability, mark Chef Specials, or delete dishes.
3. **Gallery Management**: Upload and remove gallery photos.
4. **Restaurant Settings**: Live edit contact phone, WhatsApp number, address, and opening hours.
