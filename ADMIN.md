# Admin Portal Documentation

## Accessing Admin Panel

- **Route**: `/admin`
- **Login Route**: `/admin/login`
- **Authentication**: Secured via Supabase Auth. Authorized staff users are provisioned through Supabase Dashboard Auth Users.

## Features

1. **Food Photography Replacement Center**: Visual replacement progress tracker, one-click upload for real restaurant photos, version rollback, and duplicate detection.
2. **System Overview**: Live metrics on menu counts, chef specials, gallery items, and system health.
3. **Menu Management**: Create, edit, toggle availability, mark Chef Specials, or delete dishes.
4. **Gallery Management**: Upload and manage storefront and interior gallery photos.
5. **Restaurant Settings**: Live edit contact phone, WhatsApp number, address, and opening hours.
6. **Public Listing Sync**: Review and synchronize information across Google Maps, Justdial, and Magicpin.
